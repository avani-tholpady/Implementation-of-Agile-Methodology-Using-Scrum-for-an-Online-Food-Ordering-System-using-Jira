# 🍔 Online Food Ordering System – Agile Scrum Project

## 📌 Project Overview

This project demonstrates the implementation of **Agile methodology** using the **Scrum framework** for managing the development of an **Online Food Ordering System**.  

The project was carried out using **Jira** to create, organize, and track tasks in a structured and efficient manner.

---

## 🎯 Objective

The main objective of this project is to understand how Agile practices are applied in real-world software development.  

It focuses on:

- Creating user stories  
- Breaking user stories into smaller tasks  
- Managing tasks using sprints  
- Tracking progress efficiently  
- Understanding Scrum workflow  

---

## 🛠 Tools and Technologies

- **Jira** – Task management and sprint planning  
- **Agile Methodology** – Iterative development process  
- **Scrum Framework** – Sprint-based project management  

---

## 📋 Features (User Stories)

The following user stories were created for the system:

- 🍽 Browse Restaurants  
- 📜 View Menu  
- 🛒 Add to Cart  
- ✅ Place Order  
- 🚚 Track Order  
- 🔐 User Login  

---

## 🔄 Project Workflow

The project followed these steps:

1. Created user stories for the system  
2. Divided user stories into smaller tasks  
3. Assigned priority to each task  
4. Created a sprint in Jira  
5. Managed tasks through different stages:

- **To Do**  
- **In Progress**  
- **Done**

---

## 📊 Sprint Management

- Tasks were organized into a sprint backlog  
- Progress was monitored using the Jira board  
- Tasks were updated regularly based on status  
- Sprint completion was reviewed after task completion  

---

## ✅ Results

This project successfully demonstrates how **Agile Scrum** helps in organizing and managing tasks efficiently.  

It provides a clear understanding of:

- Task planning  
- Sprint execution  
- Workflow management  
- Progress tracking  
- Team-oriented project structure  

---

## 🚧 Limitations

- This is a simulation project (no actual coding involved)  
- Limited team collaboration (individual project work)  
- Focused mainly on project management practices
