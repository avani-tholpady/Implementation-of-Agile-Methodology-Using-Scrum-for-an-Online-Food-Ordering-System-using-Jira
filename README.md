Online Food Ordering System – Agile Scrum Project
📌 Project Overview

This project demonstrates the implementation of Agile methodology using the Scrum framework for managing the development of an Online Food Ordering System. The project was carried out using Jira to create, organize, and track tasks in a structured way.

🎯 Objective

The main objective of this project is to understand how Agile practices are used in real software development. It focuses on:

Creating user stories
Dividing them into smaller tasks
Managing tasks using sprints
Tracking progress efficiently

🛠 Tools and Technologies
Jira (Task Management Tool)
Agile Methodology
Scrum Framework

📋 Features (User Stories)
Browse Restaurants
View Menu
Add to Cart
Place Order
Track Order
User Login

🔄 Project Workflow
Created user stories for the system
Broke down user stories into smaller tasks
Assigned priority to each task
Created a sprint in Jira
Moved tasks through stages:
To Do
In Progress
Done

📊 Sprint Management
Tasks were organized into a sprint
Progress was tracked using Jira board
Tasks were updated regularly based on status

✅ Results
The project successfully shows how Agile Scrum helps in organizing and managing tasks efficiently. It provides a clear understanding of workflow, task tracking, and project management.

🚧 Limitations
This is a simulation project (no actual coding)
Limited team collaboration (individual work)
